# data/ — Dataset Directory

This directory contains all raw and processed data for the NIFTY50-VQC project.

---

## Subdirectories

### raw/
Original, unmodified NIFTY 50 yearly CSV files (2015-2025).
- Source: User-provided local files (National Stock Exchange of India)
- Format: One CSV per year, columns: Date, Open, High, Low, Close, Volume, Shares Traded, Turnover
- These files are NEVER modified — all processing writes to processed/

### processed/
Clean, analysis-ready data files generated by the pipeline scripts.

| File | Generated By | Description |
|------|-------------|-------------|
| nifty50_combined.csv | Phase 7 (EDA) | All yearly CSVs merged, columns standardised |
| nifty50_with_target.csv | Phase 8 | Combined CSV + binary UP/DOWN target variable |
| nifty50_features.csv | Phase 9 | With 8 technical indicators, NaN warmup rows dropped |
| nifty50_scaled_data.npz | Phase 10 | Scaled train/val/test numpy arrays (StandardScaler + MinMaxScaler) |
| nifty50_pca_4d.npz | Phase 12 | 4D PCA quantum-encoded arrays for 4-qubit VQC input |

---

## Dataset Statistics

| Property | Value |
|----------|-------|
| Index | NIFTY 50 (National Stock Exchange of India) |
| Period | 2015-01-29 to 2025-12-30 |
| Frequency | Daily (trading days only) |
| Raw rows | 2,726 (before warmup drop) |
| Clean rows | 2,706 (after 19-day SMA warmup dropped) |
| Features | 8 technical indicators |
| Target | Binary: 1=UP (Close_{t+1} > Close_t), 0=DOWN |

## Train / Validation / Test Split

| Split | Period | Rows | % | UP Days | DOWN Days |
|-------|--------|------|---|---------|----------|
| Train | 2015-2022 | 1,963 | 72.5% | 53.49% | 46.51% |
| Validation | 2023-2024 | 495 | 18.3% | 56.16% | 43.84% |
| Test | 2025 | 248 | 9.2% | 50.00% | 50.00% |

## NPZ File Contents

### nifty50_scaled_data.npz
`python
import numpy as np
data = np.load('data/processed/nifty50_scaled_data.npz', allow_pickle=True)
# Keys: X_train_std, X_val_std, X_test_std      (StandardScaler output, shape [N, 8])
#       X_train_minmax, X_val_minmax, X_test_minmax  (MinMaxScaler [0,pi], shape [N, 8])
#       y_train, y_val, y_test                   (binary labels)
#       feature_cols                             (list of 8 feature names)
`

### nifty50_pca_4d.npz
`python
data = np.load('data/processed/nifty50_pca_4d.npz', allow_pickle=True)
# Keys: X_train_quantum, X_val_quantum, X_test_quantum  (PCA + [0,pi] scaled, shape [N, 4])
#       X_train_pca, X_val_pca, X_test_pca              (raw PCA output, shape [N, 4])
#       y_train, y_val, y_test                          (binary labels)
`

---

## Data Leakage Policy

> All scalers and PCA transformers are fitted **strictly on the Training set (2015-2022)**.
> Validation and Test sets are transformed using training parameters only.
> Raw files in raw/ are NEVER modified.
