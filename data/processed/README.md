# data/processed/ — Processed Data Files

This directory contains all data files generated by the pipeline scripts.
Files here are safe to delete and regenerate by re-running the phase scripts.

---

## Data Pipeline Order

`
Raw CSVs (data/raw/)
  -> nifty50_combined.csv       [Phase 7: EDA + combine]
  -> nifty50_with_target.csv    [Phase 8: Add UP/DOWN label]
  -> nifty50_features.csv       [Phase 9: Compute 8 technical features]
  -> nifty50_scaled_data.npz    [Phase 10: Temporal split + StandardScaler + MinMaxScaler]
  -> nifty50_pca_4d.npz         [Phase 12: PCA 8D->4D + MinMaxScaler [0,pi]]
`

## Scaler Parameters (all fit on Train 2015-2022 ONLY)

- **StandardScaler:** mean and std from 1,963 training rows → applied to Val+Test
- **MinMaxScaler [0, pi]:** min and max from 1,963 training rows → applied to Val+Test
- **PCA:** components from 1,963 training rows → applied to Val+Test
- **Quantum scaler [0, pi]:** min/max from 1,963 training PCA outputs → applied to Val+Test
